# AirRoom para Windows

Controle um ar-condicionado Hisense vinculado ao ConnectLife diretamente pelo PC.

## Download

Baixe a versão mais recente na página de [Releases](https://github.com/youngchosen/AirRoom-Downloads/releases/latest).

O arquivo é portátil: basta baixar `AirRoom.exe` e abrir. Não é necessário instalar.

## Como conectar sua conta

1. Abra o `AirRoom.exe`.
2. Entre em **Configurações**.
3. Abra **ConnectLife**.
4. Informe o e-mail e a senha da sua própria conta ConnectLife.
5. Selecione o ar-condicionado encontrado. O AUID é opcional.

Cada pessoa deve usar a própria conta ConnectLife e ter o aparelho previamente adicionado no aplicativo oficial.

## Widget da Área de Trabalho

Em **Configurações**, ative **Widget na Área de Trabalho**. O widget:

- fica junto aos elementos do desktop, sem sobrepor outros aplicativos;
- pode ser arrastado para outro lugar ou monitor;
- salva a posição escolhida;
- reaparece automaticamente ao iniciar o Windows.

## Privacidade

O AirRoom não inclui nenhuma conta configurada. A sessão ConnectLife é criada no computador do usuário e protegida localmente pelo Windows.

## Requisitos

- Windows 10 ou Windows 11;
- conexão com a internet;
- conta ConnectLife com um aparelho Hisense já vinculado;
- Microsoft Edge WebView2, normalmente incluído no Windows.

Se o Windows SmartScreen exibir um aviso por o aplicativo ainda não possuir assinatura comercial, escolha **Mais informações** e depois **Executar assim mesmo** somente se o arquivo tiver sido baixado deste repositório.
